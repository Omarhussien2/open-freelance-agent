# التشغيل اليومي — كيف يعمل الوكيل كل يوم ولا "يسقط"

الوكيل المكتبي يحتاج ثلاث طبقات تشغيل مستمرة. إذا سقطت أي طبقة، تعيدها الطبقة الأعلى
تلقائيًا في الفحص الصباحي — لذلك لا يوجد "زر واحد يوقف كل شيء" إلا زر القتل المقصود.

## الطبقات الثلاث

| الطبقة | ماذا تفعل | كيف تعمل |
| --- | --- | --- |
| 1. المهمة اليومية المجدولة | جولة الرصد + الفلترة + المسودات + التقرير | مجدول مهام (Scheduler) يشغلها مرة يوميًا |
| 2. المراقب الدائم (watcher) | يسمع بوت تليجرام ويرد بتأكيدات فورية | عملية خلفية تعمل طوال الوقت |
| 3. خدمة المتصفح (Cua Driver) | تشغيل المتصفح المعزول عند الحاجة | خدمة/عملية خلفية + تشغيل تلقائي عند الإقلاع |

## 1) المهمة اليومية المجدولة (Windows Task Scheduler)

مثال: تشغيل الجولة كل يوم 9:00 صباحًا. أنشئ ملف `run_daily_round.bat` بجانب سكربتات
الوكيل يشغّل جولتك، ثم سجّله مرة واحدة من موجه الأوامر (cmd كمسؤول غير مطلوب لمهام المستخدم):

```bat
@echo off
cd /d "%~dp0"
python agent_loop.py --task "daily scan round" >> daily_round.log 2>&1
```

```bat
schtasks /create /tn "FreelanceAgentDaily" /tr "C:\path\to\run_daily_round.bat" /sc daily /st 09:00
```

ملاحظات:
- إذا كان الجهاز مغلقًا في وقت التنفيذ، أضف `/z` أو شغّلها عند الإقلاع — أو ببساطة اجعل
  المهمة "تشغّل بأقرب فرصة" من واجهة Task Scheduler (صندوق Run task as soon as possible after a scheduled start is missed).
- القاعدة الذهبية للجولة اليومية: **رصد وقرار فقط**. أي تقديم يحدث حصريًا عبر مهمة منفصلة
  تحقق موافقة صريحة (زر الموافقة أو النص المعدّل) — الجولة اليومية لا تقدم شيئًا بنفسها.
- احترم حدود المنصات (مثلًا عرض واحد كل 24 ساعة لكل منصة) لحماية الحساب من الحظر.

## 2) إبقاء المراقب حيًا

المراقب عملية خفيفة (peek كل 15 ثانية). طريقتان لإبقائه:

- **الأبسط:** سجّله في مجدول المهام عند تسجيل الدخول:
  `schtasks /create /tn "FreelanceAgentWatcher" /tr "python D:\path\watch_approval.py" /sc onlogon`
- **أو** يعيد تشغيله الفحصُ الصباحي للمهمة اليومية إذا لم يجده حيًّا (نمط "الطبقة العليا تُصلح الأسفل").

المهم: المراقب **لا يستهلك** طابور تحديثات تليجرام (يقرأ بدون offset-confirming)، لذلك
مهمة التقديم تظل ترى القرار كاملًا عند وقتها.

## 3) خدمة المتصفح

- التثبيت الرسمي يسجل تشغيلًا تلقائيًا (قد يطلب موافقة UAC مرة واحدة) — أو شغّلها يدويًا:
  `cua-driver serve`
- للتحقق: `cua-driver status` — وللفحص الشامل: `cua-driver doctor`.

## ماذا لو سقط كل شيء؟

أعد التشغيل بالترتيب: خدمة المتصفح ← المراقب ← انتظر الجولة اليومية التالية (أو شغّل الـbat يدويًا).
كل القرارات (الموافقات والنصوص المعدّلة) محفوظة في طابور تليجرام حتى 24 ساعة وفي سجل
شيت الموافقات، فلا يضيع قرار بسبب إعادة تشغيل.

## زر القتل (الإيقاف الكامل)

أوقف المهمة اليومية والمراقب من Task Scheduler (حذف المهمتين) + أغلق خدمة المتصفح
(`cua-driver stop`). لا شيء يعمل بعدها، ولا يُرسل أي شيء دونك.
