# دليل التركيب — خطوة بخطوة (لا تحتاج أي خبرة تقنية)

مدة التركيب المتوقعة: 30–45 دقيقة. كل شيء مجاني. نفّذ المراحل بالترتيب دون تخطي أي خطوة.

## المرحلة (أ): تثبيت Cua Driver على ويندوز

1. افتح قائمة «ابدأ»، اكتب PowerShell، ثم افتح **Windows PowerShell**.
2. انسخ الأمر الرسمي التالي، الصقه في النافذة، واضغط Enter:
   ```powershell
   irm https://cua.ai/driver/install.ps1 | iex
   ```
3. انتظر حتى تنتهي عملية التثبيت.
4. بعد انتهاء التثبيت، اكتب الأمر التالي واضغط Enter:
   ```powershell
   cua-driver serve
   ```
5. اترك هذه النافذة مفتوحة — هي قلب أتمتة المتصفح، ولا يعمل الوكيل بدونها.

## المرحلة (ب): إنشاء بوت تليجرام ونسخ التوكن

1. افتح تليجرام وابحث عن **@BotFather** (عليه علامة توثيق رسمية).
2. أرسل له الأمر `/newbot`.
3. سيسألك عن اسم البوت: اكتب أي اسم تريده (مثلًا: My Work Approvals).
4. سيسألك عن معرّف ينتهي بـ `bot` (مثلًا: `YourApprovalsBot`) — سيصبح بوتك `@YourApprovalsBot`.
5. سيرسل لك **توكن** (سطر طويل من أرقام وحروف). انسخه واحتفظ به في مكان آمن — لا ترسله لأي أحد.
6. افتح بوتك الجديد من حسابك واضغط **Start** (أو أرسل `/start`). بدون هذه الخطوة لن يرد عليك البوت أبدًا.

## المرحلة (ج): شيت جوجل + Apps Script

1. افتح Google Sheets وأنشئ شيتًا جديدًا (اسمًا مثلًا: Freelance Tracker).
2. أنشئ 3 تبويبات وسمِّها بالضبط: **السجل** — **قايمة اليوم** — **الموافقات**.
3. من القائمة اختر **Extensions ← Apps Script**.
4. من مجلد `apps-script` في المشروع، افتح ملف `Code.gs` وانسخ كل محتواه.
5. الصقه في المحرر مكان أي كود موجود، ثم اضغط **Save** (أيقونة القرص).
6. إن وُجد في الكود متغير للبريد، ضع بريدك مكان `your-email@gmail.com`.
7. اختر الدالة الرئيسية من الشريط ثم اضغط **Run** مرة واحدة.
8. ستظهر شاشة صلاحيات جوجل: اضغط **Review permissions** ثم اختر حسابك.
9. قد تظهر رسالة «Google hasn't verified this app» — طبيعية، فهذا كودك الخاص: اضغط **Advanced** ← **Go to ... (unsafe)** ← **Allow**.
10. ظهور رسالة نجاح أو سجل تنفيذ = كل شيء تم.

## المرحلة (د): تسجيل الدخول في متصفح الوكيل — مرة واحدة فقط

1. تأكد أن `cua-driver serve` ما زال يعمل في نافذة PowerShell.
2. شغّل الوكيل لأول مرة — ستُفتح نافذة متصفح Chromium معزولة.
3. سجّل دخولك **بنفسك** إلى كل منصة (مستقل / Upwork / LinkedIn) من داخل هذه النافذة.
4. البروفايل دائم ومسمّى: لن تحتاج لتسجيل الدخول مرة أخرى إلا لو غيّرت جهازك.
5. تذكّر: الوكيل لا يرى ولا يخزّن كلمة سر — أنت من يسجّل الدخول بيده.

## المرحلة (هـ): تعبئة ملفات الإعداد

1. افتح مجلد `agent`.
2. انسخ `telegram_token.txt.example` وأعد تسمية النسخة إلى `telegram_token.txt`.
3. افتح النسخة والصق توكن البوت (من المرحلة ب) مكان النص التجريبي، واحفظ.
4. بنفس الطريقة: انسخ `telegram_chat_id.txt.example` إلى `telegram_chat_id.txt` وضع فيه رقم محادثتك مع البوت، وانسخ `openrouter_key.txt.example` إلى `openrouter_key.txt` وضع فيه مفتاح OpenRouter الخاص بك.
5. هذه الملفات المحلية مستثناة من Git تلقائيًا عبر `.gitignore` — لا ترفعها لأي مكان.

## المرحلة (و): أول تشغيل تجريبي

1. افتح نافذة PowerShell جديدة داخل مجلد المشروع.
2. شغّل سكربت المراقبة الدائم:
   ```powershell
   python agent/watch_approval.py
   ```
3. أرسل `/start` إلى بوتك — يجب أن يرد فورًا برسالة تأكيد.
4. في نافذة ثانية شغّل الوكيل وراقب أول دورة فحص:
   ```powershell
   python agent/agent_loop.py
   ```
5. عند وصول أول مسودة على تليجرام: جرّب زر الموافقة، وجرّب التعديل بإرسال النص البديل. بعدها تبدأ يومك الحقيقي.

## مشاكل شائعة

| المشكلة | الحل |
| --- | --- |
| البوت لا يرد | هل ضغطت **Start** أول مرة؟ وهل التوكن ملصوق صح في `telegram_token.txt`؟ |
| المتصفح لا يفتح | هل `cua-driver serve` يعمل في نافذة PowerShell؟ شغّله ثم أعد المحاولة |
| شاشة تحذير جوجل عند أول تشغيل | طبيعية — إنه كودك الخاص؛ اضغط Advanced ثم Allow |
| الوكيل متوقف بعد إعادة تشغيل الجهاز | أعد فتح PowerShell وشغّل `cua-driver serve` ثم الوكيل |
| لا تظهر مشاريع | تأكد من تبويب «قايمة اليوم» ومن أن الفلتر (remote/hybrid) ليس أضيق من اللازم |

## قبل أن تبدأ يومك الأول

- التكلفة الكاملة: **0** — الموديلات المُختبرة على OpenRouter مجانية (`:free`).
- للإيقاف الفوري الكامل: أغلق نافذة `cua-driver serve` ونوافذ الوكيل — هذا هو مفتاح الإيقاف.
- للحذف الكامل من الجهاز: راجع `SECURITY.md`.
