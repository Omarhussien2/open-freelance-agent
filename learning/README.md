# ذاكرة الخبرة (Self-Learning Layer)

- قبل كل مهمة: `python learning/lessons_read.py <topic keywords>` واقرا المخرجات.
- بعد كل مفاجأة: اكتب topic/context/lesson/rule في `learning/incoming_lesson.txt` ثم `python learning/lessons_add.py`.
- القاعدة قابلة للتنفيذ، والسجل append-only، ومراجعة بشرية أسبوعية 10 دقائق.
- الترقية لاحقًا: ذاكرة دلالية (cognee/mem0 محلي) لما يتعدى الدروس 100.
